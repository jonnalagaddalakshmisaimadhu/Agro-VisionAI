PROBLEM 1: INDIAN REGIONAL LANGUAGES & VOICE-FIRST ACCESSIBILITY
----------------------------------------------------------------------------------------------------
Current Limitation : English text UI; unusable by non-English-literate farmers.
FOSS / Free Solution:
  1. BHASHINI API (Govt of India Open Source Initiative)
     - What it gives: Free Speech-to-Text (ASR), Text-to-Speech (TTS), and Neural Machine Translation
       for 22 Indian scheduled languages (Hindi, Telugu, Tamil, Marathi, Bengali, Kannada, Punjabi, etc.).
     - Cost: 100% Free for Indian startups & research.
     - Integration: Direct REST API in Python / JavaScript.
  2. WHISPER.CPP (OpenAI Whisper in C++)
     - What it gives: Run speech recognition directly on mobile device CPU/Android without internet.
     - Cost: 100% Free (MIT License).

PROBLEM 2: REAL-TIME FIELD LEAF DETECTION & OFFLINE EDGE INFERENCE
----------------------------------------------------------------------------------------------------
Current Limitation : 210MB PyTorch model requires server upload & cropped leaf images; fails on blurry photos.
FOSS / Free Solution:
  1. YOLOV8-NANO / YOLOV11-NANO (Ultralytics)
     - What it gives: Object detection that automatically locates diseased spots and leaves inside
       a full plant photo with bounding boxes in <15ms.
     - Cost: Open-source (AGPL-3.0).
  2. TFLITE / ONNX RUNTIME MOBILE
     - What it gives: Converts model into a <15MB file embedded directly inside the Android APK.
     - Result: 100% OFFLINE detection on the farmer's phone in remote fields with zero server costs.

PROBLEM 3: REAL-TIME TELE-AGRONOMY VIDEO CONSULTATIONS
----------------------------------------------------------------------------------------------------
Current Limitation : Mock video UI without real live WebRTC streaming.
FOSS / Free Solution:
  1. LIVEKIT (Apache 2.0 Open Source)
     - What it gives: Enterprise WebRTC video/audio conferencing server; high-quality mobile streaming.
     - Cost: 100% Open-source self-hostable (Free Cloud Tier: 100GB/mo).
  2. PEERJS (P2P WebRTC)
     - What it gives: Direct browser-to-browser encrypted video calling with zero media server bandwidth.
     - Cost: 100% Free (MIT License).

PROBLEM 4: RELIABLE MANDI MARKET PRICES & COMMODITY DATA
----------------------------------------------------------------------------------------------------
Current Limitation : Agmarknet API downtime and lack of local mandi granularity.
FOSS / Free Solution:
  1. SCRAPY + PLAYWRIGHT PYTHON (Open-Source Web Harvesting)
     - What it gives: Automated headless scraper fetching daily price bulletins directly from state
       APMC portals (e-NAM, Agmarknet, State Mandi Boards) into a local database every morning at 6 AM.
     - Cost: 100% Free (BSD/Apache License).
  2. DATA.GOV.IN OPEN DATA OGD PLATFORM
     - What it gives: Official Government API keys for commodities data.
     - Cost: Free government registration.

PROBLEM 5: PRECISION SOIL & SATELLITE VEGETATION TELEMETRY
----------------------------------------------------------------------------------------------------
Current Limitation : Regional weather approximations rather than plot-level soil parameters.
FOSS / Free Solution:
  1. ISRIC SOILGRIDS 250M REST API
     - What it gives: Global open-source soil database providing real pH, Organic Carbon, Cation
       Exchange Capacity, and Clay/Sand/Silt fractions at 250m resolution using GPS coordinates.
     - Cost: 100% Free Open Data.
  2. COPERNICUS OPEN ACCESS HUB (Sentinel-2 Satellite)
     - What it gives: Free 10m-resolution multi-spectral imagery to compute NDVI (crop greenness & health)
       for farm plots automatically.
     - Cost: Free open data from European Space Agency (ESA).
  3. OPEN-METEO API
     - What it gives: Free agricultural meteorological parameters, hourly solar radiation, and soil moisture.
     - Cost: Free for open usage.

PROBLEM 6: MAPS, STORE LOCATOR & GEOLOCATION
----------------------------------------------------------------------------------------------------
Current Limitation : Google Maps API requires billing accounts and incurs pay-per-load charges.
FOSS / Free Solution:
  1. LEAFLET.JS + OPENSTREETMAP (OSM)
     - What it gives: Lightweight interactive map controls with tile rendering.
     - Cost: 100% Free & Open Source (No credit card or billing ever required).
  2. NOMINATIM OPENSTREETMAP
     - What it gives: Free reverse geocoding (Coordinates to Village/District/State).
     - Cost: 100% Free.

PROBLEM 7: PRODUCTION DATABASE, CACHING & WEBSOCKET SYNC
----------------------------------------------------------------------------------------------------
Current Limitation : SQLite locks during concurrent writes; WebSocket chat is isolated to single-worker memory.
FOSS / Free Solution:
  1. POSTGRESQL + PG_TRGM (Full Text Search)
     - Free Cloud Tiers: Supabase (500MB free Postgres) / Neon.tech (0.5GB serverless Postgres).
     - Cost: Open Source (PostgreSQL License).
  2. REDIS PUB/SUB
     - What it gives: Broadcasts community chat messages across all backend server instances.
     - Free Cloud Tier: Upstash (10,000 commands/day free serverless Redis).

PROBLEM 8: ZERO-COST PRODUCTION CLOUD DEPLOYMENT
----------------------------------------------------------------------------------------------------
FOSS / Free Solution:
  - Frontend Hosting: Firebase Hosting / Vercel (Free 100GB bandwidth/month).
  - Backend API: Render.com / Fly.io / HuggingFace Spaces (Free CPU & Docker instances).
  - Mobile App: Android Studio + Capacitor build (100% Free local APK generation).
