1. EXECUTIVE PROJECT OVERVIEW & VALUE PROPOSITION
====================================================================================================
Agro-VisionAI (FarmIQ AI Agro) is an integrated, full-stack agritech enterprise platform engineered to
solve the core bottlenecks faced by traditional farmers, extension workers, and aquaculture operators.

THE PROBLEM WE SOLVE:
- 20% to 40% of agricultural yields are destroyed annually due to unaddressed or misdiagnosed crop diseases.
- Farmers lack real-time market price visibility and suffer severe margin loss to middlemen.
- Soil health degrades and capital is wasted due to arbitrary, non-scientific fertilizer application.
- Smallholder farmers cannot afford ₹5 Lakh to ₹15 Lakh tractors, harvesters, and solar pumps.
- Opaque, fragmented government subsidies go unclaimed due to complex bureaucratic procedures.
- Inland aquaculture farmers lack digital water telemetry tools, feed conversion calculators, and seed markets.

OUR SOLUTION:
Agro-VisionAI unifies localized deep learning computer vision, geo-spatial soil classification, live IoT
meteorological telemetry, automated government mandi scraping, a peer-to-peer equipment sharing economy,
and a specialized aquaculture management hub into a single, high-performance responsive web and native
mobile application.

5. ARTIFICIAL INTELLIGENCE, DEEP LEARNING & MACHINE LEARNING
====================================================================================================

5.1 PYTORCH 39-CLASS PLANT DISEASE CNN (`Backend/models/CNN.py`):
- Model File: `Backend/models/Final ML Model/plant_disease_model_1_latest.pt` (210 MB weights).
- Framework: PyTorch 2.5.0 + Torchvision 0.20.0.
- Model Architecture:
  * 4 Convolutional Stages with Batch Normalization & ReLU activations:
    - Stage 1: Conv2D(3->32, k=3, p=1) -> ReLU -> BatchNorm2D(32) -> Conv2D(32->32) -> MaxPool(2)
    - Stage 2: Conv2D(32->64, k=3, p=1) -> ReLU -> BatchNorm2D(64) -> Conv2D(64->64) -> MaxPool(2)
    - Stage 3: Conv2D(64->128, k=3, p=1) -> ReLU -> BatchNorm2D(128) -> Conv2D(128->128) -> MaxPool(2)
    - Stage 4: Conv2D(128->256, k=3, p=1) -> ReLU -> BatchNorm2D(256) -> Conv2D(256->256) -> MaxPool(2)
  * Fully Connected Classifier:
    - Flatten to 50,176 features -> Dropout(0.4) -> Linear(50176, 1024) -> ReLU -> Dropout(0.4) -> Linear(1024, 39)
- Preprocessing: Resize to 224x224 RGB, ToTensor(), Normalization with mean/std.
- 39 Supported Plant Disease Classes:
  Apple (Scab, Black rot, Cedar apple rust, Healthy), Blueberry (Healthy), Cherry (Powdery mildew, Healthy),
  Corn (Cercospora leaf spot, Common rust, Northern Leaf Blight, Healthy), Grape (Black rot, Esca, Leaf blight,
  Healthy), Orange (Citrus greening), Peach (Bacterial spot, Healthy), Pepper Bell (Bacterial spot, Healthy),
  Potato (Early blight, Late blight, Healthy), Raspberry (Healthy), Soybean (Healthy), Squash (Powdery mildew),
  Strawberry (Leaf scorch, Healthy), Tomato (Bacterial spot, Early blight, Late blight, Leaf Mold, Septoria,
  Spider mites, Target Spot, Yellow Leaf Curl Virus, Mosaic virus, Healthy), Background without leaves.

5.2 GOOGLE GEMINI 1.5 FLASH MULTIMODAL VISION:
- Model: `gemini-1.5-flash-latest` / `gemini-pro-vision` via `@google/generative-ai` and `google-generativeai`.
- Purpose: Automated fallback when local PyTorch model encounters an unlisted or novel crop species.

5.3 GROQ LLAMA-3.3-70B 5-POINT BOTANICAL REASONING (`groq_service.py`):
- Model: `llama-3.3-70b-versatile` via Groq Cloud API in JSON mode.
- Output Format: Strictly formats diagnostic outputs into:
  * Exactly 5 Observable Symptoms (chlorosis, spots, wilting, curling, fungal growth).
  * Exactly 5 Curative Treatments (chemical fungicides, bactericides, bio-pesticides, dosages).
  * Exactly 5 Preventive Measures (soil aeration, resistant hybrids, drip irrigation, crop rotation).

5.4 GROQ LLAMA-3.1-8B-INSTANT CONVERSATIONAL AGENT (`chatbot.py`):
- Model: `llama-3.1-8b-instant`.
- Purpose: Sub-second latency agronomic conversational Q&A with system prompts prioritizing practical,
  organic, and cost-effective farming techniques.

5.5 GEOSPATIAL SOIL KNN CLASSIFIER (`soil_knn.py`):
- Dataset: `Backend/data/all_india_csv/india_district_soil_with_npk.csv` (700+ Indian districts).
- Model Binary: `soil_knn_model.pkl` (Scikit-Learn K-Nearest Neighbors Classifier).
- Algorithm: Converts latitude and longitude to spherical radians. Finds nearest district centroid to
  determine dominant Soil Type (Alluvial, Black, Red, Laterite, Desert) and estimated NPK ratios.
- Fallback: Mathematical Haversine distance nearest-neighbor algorithm.

5.6 RULE-BASED NLP & ENTITY RECOGNITION (`nlp_service.py`):
- 12 Intent Classifiers (CROP_RECOMMENDATION, DISEASE_DIAGNOSIS, PEST_MANAGEMENT, MARKET_INQUIRY, etc.).
- Entity extraction for crops, seasons, locations, pests, and price limits.

8. END-TO-END WORKFLOW OF ALL 12 CORE MODULES
====================================================================================================

8.1 AI PLANT DISEASE DETECTION & IN-APP CONSULTATION:
- User clicks photo of affected leaf using mobile camera or uploads image.
- Image is converted to a base64 tensor and sent to `POST /api/disease/predict`.
- PyTorch CNN evaluates the image against 39 classes.
- If confidence score is high, the label is passed to Groq LLaMA 3.3 70B to generate the 5-point report.
- The UI renders severity badge, confidence bar, symptoms, treatments, and preventions.
- An embedded AI chat box (`EmbeddedAIChat.tsx`) opens directly with pre-loaded diagnostic context.

8.2 INTELLIGENT CROP & SOIL RECOMMENDATION:
- Farmer inputs land area, budget, season, and previous crop.
- The system resolves geo-coordinates via browser GPS, queries `soil_knn_model.pkl` to determine soil
  type and NPK values, and queries Open-Meteo for live soil moisture.
- Generates 6 ranked crop suggestions with duration, input investment, and calculated net profit.

8.3 REAL-TIME MANDI PRICES & PRICE ALERT SUBSYSTEM:
- Ingests prices from Agmarknet API every 2 hours.
- Farmers filter by state, district, or crop.
- Displays 6-month historical Recharts price charts with trend indicators (Bullish/Bearish).
- Farmers create custom price alerts that trigger notifications when target prices are reached.

8.4 PEER-TO-PEER FARM EQUIPMENT RENTAL MARKETPLACE:
- Machinery owners list tractors, harvesters, tillers, and sprayers with hourly/daily pricing.
- Renters select equipment, pick dates on an interactive calendar, review automatic cost calculations,
  and submit booking requests.
- Tracks booking status from Pending to Approved, Active, and Completed.

8.5 FARMER DIRECT PRODUCE MARKETPLACE:
- Farmers list harvested produce with photos, pricing per kg/quintal, and organic certification badges.
- Direct buyers and wholesalers search produce by location and price.
- In-app chat modal (`MarketplaceChatModal.tsx`) enables direct negotiation and order finalization.

8.6 GOVERNMENT SUBSIDY & SCHEME AGGREGATOR:
- Displays curated Central and State schemes (PM-KISAN, PMFBY, SMAM, PMKSY).
- Farmers filter by subsidy type and state, review eligibility criteria and required documents, and
  click direct links to official government application portals.

8.7 HYPER-LOCAL WEATHER FORECASTS & AGRO-ADVISORIES:
- Displays real-time temperature, humidity, wind, and 5-day / 3-hour forecasts.
- Evaluates real-time parameters to provide an Operational Suitability Score for spraying, sowing,
  irrigation, and harvesting.

8.8 AQUACULTURE & FISHERIES MANAGEMENT SUITE (AQUASESSION):
- `AquaFarmersView`: Live water telemetry monitor (pH, Dissolved Oxygen, Salinity, Temperature).
- `AquaToolsView`: Automated calculators for Feed Conversion Ratio (FCR), Pond Biomass, Stocking Density,
  and chemical treatment dosing.
- `AquaMarketplaceView`: Trading platform for fish fingerlings, shrimp PL-10 larvae, and aqua feed.
- `AquaMarketBuyersView`: Direct exporter and wholesale buyer portal for seafood contracts.

8.9 VOICE-ENABLED MULTILINGUAL AI AGRONOMIST CHATBOT:

11. STEP-BY-STEP INSTALLATION & RUNNING GUIDE
====================================================================================================

OPTION 1: 1-CLICK AUTOMATED STARTUP (WINDOWS)
Execute:
  start-project.bat
(Launches Backend on http://127.0.0.1:8000 and Frontend on http://localhost:8080)

OPTION 2: MANUAL STARTUP
1. Start Backend:
   cd Backend
   python -m venv venv
   .\venv\Scripts\activate      # Windows (or source venv/bin/activate on Linux/Mac)
   pip install -r requirements.txt
   python main.py

2. Start Frontend:
   cd Frontend
   npm install
   npm run dev

ACCESS URLS:
- Frontend Application : http://localhost:8080
- Backend REST API     : http://localhost:8000
- Swagger API Docs     : http://localhost:8000/docs
- ReDoc API Docs       : http://localhost:8000/redoc
