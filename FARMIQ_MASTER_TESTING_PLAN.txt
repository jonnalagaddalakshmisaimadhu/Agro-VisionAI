PART 1: 📋 ARCHITECTURE & PROJECT TEST BOUNDARIES
====================================================================================================
1. Scope:
   FarmIQ is an all-in-one digital ecosystem for Indian agriculture combining AI-driven agronomy,
   real-time weather intelligence, machinery hiring, input commerce, and government scheme awareness.

2. Application Layers:
   - Client Tier     : Single-Page Application (React + Vite), Android Native WebView (Capacitor).
   - API Tier        : FastAPI asynchronous server with CORS, WebSockets, and JWT Auth.
   - Intelligence Tier: Scikit-learn (Crop Recommendation, Soil KNN), PyTorch/TensorFlow Vision AI,
                       Gemini / OpenAI agricultural prompt pipeline.
   - Persistence Tier: SQLite (Relational entity models), MongoDB (Community chat messages & history).
   - Resilience Tier : React ErrorBoundary wraps every module to prevent white screens.
